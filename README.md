# Personal-Expense-Tracker
A Python-based command-line application that allows users to add and manage expenses, calculate total spending, and identify the highest and lowest expenses using lists, dictionaries, loops, and conditional statements.

## Features

* Add expenses with category and amount
* Calculate total expenses
* Find the highest expense
* Find the lowest expense
* Handle invalid menu choices
* Handle cases when no expenses are added

## Technologies Used

* Python
* Lists
* Dictionaries
* Loops
* Conditional Statements
* User Input

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/vishnuu4/personal-expense-tracker.git
```

2. Navigate to the project directory:

```bash
cd personal-expense-tracker
```

3. Run the program:

```bash
python expense_tracker.py
```
